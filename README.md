# finance-fetch

Homepage, privacy policy and terms for a personal Google OAuth client used by one household. Google requires these pages before an External OAuth app can be published to production, even if only one person uses it.

The client requests only `gmail.readonly`. A script on the owner's computer uses it to download bank and investment statement attachments from the Gmail accounts of household members who sign in; nothing leaves that computer.

Served by GitHub Pages from the repository root: [vshikhar95.github.io/finance-fetch](https://vshikhar95.github.io/finance-fetch/).
